# 🧩 Web Components Collection

Kumpulan eksperimen, latihan, dan komponen antarmuka web (UI Components) yang dibangun menggunakan **HTML5** dan **CSS3**. Repository ini berfungsi sebagai galeri komponen modular serta sarana dokumentasi proses belajar pengembangan antarmuka web.

---

## 📂 Daftar Komponen

| No | Nama Komponen | Deskripsi Singkat |
| :---: | :--- | :--- |
| 1 | **3D Button** | Eksperimen tombol interaktif dengan efek bayangan dan transisi 3D. |
| 2 | **3D Cards** | Desain kartu konten dengan efek kedalaman atau perspektif 3D. |
| 3 | **Cards** | Desain kartu tata letak standar untuk menampilkan konten ringkas. |
| 4 | **Guest Page** | Desain antarmuka landing page / halaman penyambutan tamu. |
| 5 | **Login** | Form autentikasi login dengan styling bersih dan responsif. |
| 6 | **Movie Details** | Komponen tampilan detail informasi film beserta poster dan deskripsi. |
| 7 | **Music Player** | Tampilan antarmuka pemutar musik (audio player widget). |
| 8 | **Toogle Menu** | Navigasi menu tersembunyi dengan tombol toggle animasi. |
| 9 | **WebSpace** | Latihan eksplorasi layout antarmuka web modern. |

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur markup semantik untuk tiap komponen.
- **CSS3:** Flexbox, CSS Grid, Custom Properties, Pseudo-classes, dan CSS Animations/Transitions.
